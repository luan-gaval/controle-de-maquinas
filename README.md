# Controle de Máquinas
Sistema em PHP desenvolvido para controle de máquinas, utilizando MySQL como banco de dados.

## Requisitos
- PHP 7.4 ou superior
- MySQL 5.7 ou superior
- XAMPP (ou Apache + MySQL)

## Instalação
1. Coloque o projeto dentro da pasta `htdocs` do XAMPP.
2. Inicie o Apache e o MySQL.
3. Acesse o phpMyAdmin.
4. Importe o arquivo `database/schema.sql`.
5. Acesse o sistema pelo navegador.

## Banco de Dados
O banco de dados utilizado chama-se `controle_de_maquinas` e pode ser recriado a qualquer momento importando o arquivo `schema.sql`.
